# Grocery words

Lets `/price` understand Armenian (script or Latin letters) and the names each shop
uses. Both shops' own search already understands Armenian; this table makes the
*matching and comparison* work too, and fixes the few words a shop misses (Yerevan
City doesn't know "vosp").

**How a row works:** if you type any word in the first column, the shops are searched
for the second column, and products whose names contain any of the third column are
kept. Add a row any time — one product per row, words separated by commas.
Plurals are handled automatically (lentil = lentils).

Search terms marked ✓ were tested live on both shops (18 Oct 2026).
